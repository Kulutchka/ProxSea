1
Download the certificate
Use the Download button above and save squidCA.der.
2
Debian / Ubuntu
Copy it into the CA directory (note the .crt extension) and update the store:
sudo cp squidCA.der /usr/local/share/ca-certificates/squidCA.crt
sudo update-ca-certificates
3
Fedora / RHEL / CentOS
Copy it into the trust anchors and update:
sudo cp squidCA.der /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
Firefox note: on Linux, Firefox uses its own certificate store and ignores the system store. Import it in Firefox via Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, then check “Trust this CA to identify websites”.

Configure your browser to use the proxy

Proxy: {{ proxy_addr }}
1
Open network settings
Open the menu (☰) → Settings → General → scroll to Network Settings → click Settings….
2
Choose manual proxy configuration
Select Manual proxy configuration.
3
Enter the proxy
Set HTTP Proxy to {{ proxy_host }} and Port to {{ proxy_port }}, then check “Also use this proxy for HTTPS”.
4
Save
Click OK and try browsing — the first HTTPS visit should show no warning once the certificate is trusted.
Firefox trusts the system certificate store on Windows and macOS, so installing the CA above is enough there. On Linux, import the CA into Firefox's own store as described in the Linux certificate tab.
1
Use your system proxy settings
Chrome has no proxy settings of its own — it follows the operating system. Configure the proxy once at the OS level and Chrome will use it automatically.
2
Windows
Settings → Network & Internet → Proxy → Manual proxy setup → turn on Use a proxy server → address {{ proxy_host }}, port {{ proxy_port }} → Save.
3
macOS
System Settings → Network → select your connection → Details → Proxies → enable Web Proxy (HTTP) and Secure Web Proxy (HTTPS) with server {{ proxy_host }} and port {{ proxy_port }}.
Launch-time alternative: start Chrome with the proxy flag: 
google-chrome --proxy-server="{{ proxy_url }}"

3
Enable the proxies
Go to the Proxies tab and enable Web Proxy (HTTP) and Secure Web Proxy (HTTPS).

Enter the server
For both, set the server to {{ proxy_host }} and port to {{ proxy_port }}, then click OK and Apply.
